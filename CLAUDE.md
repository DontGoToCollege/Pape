# Pape: notes for Claude

Build, test and release recipes, decisions and gotchas, kept in the repo so every computer has them.

Pape lives at `%USERPROFILE%\Music\Claude\Projects\Pape` (repo github.com/DontGoToCollege/Pape, public). Started 2026-11-17; v0.1.0 = Phase 1 of `docs\FEATURES.md` (Phase 2 = Wallpaper Engine scene renderer, Phase 3 = app wallpapers/screensaver/LEDs).

- Clean-room like portasnap-project: WE (Steam install `C:\Program Files (x86)\Steam\steamapps\common\wallpaper_engine`, v2.8.0.42) was surveyed only via its locale strings (`locale\ui_en-us.json`), UI route list and project.json files. Never decompile wallpaper64.exe or ship WE assets; scenes must read WE's `assets\` from the install at run time.
- Stack: WinForms-only .NET 8 (no WPF; avoids type clashes) + WebView2 1.0.2903.40 + NAudio.Wasapi 2.2.1. `Engine.cs` = ApplicationContext owning config.json (the UI owns the schema and posts the whole config back), `WallpaperWindow.cs` = NativeWindow + CoreWebView2Controller per display, `Desktop.cs` = WorkerW/Progman finding, `web\` = UI (app.js) + player.html, `src\Pape\shim.js` = WE web API.
- This PC (build 28000) uses the 24H2 path: wallpapers are layered children of Progman placed just below SHELLDLL_DefView. Owner confirmed on screen 2026-11-17 (v0.1.1). PrintWindow(PW_RENDERFULLCONTENT) of Progman from a DPI-aware thread shows the composed desktop and matched what the owner saw.
- Grid layout gotcha (fixed 0.1.1): aspect-ratio on grid items inside a fixed-height scrolling grid lets rows shrink and overlap; keep the ratio on the thumb and use `grid-auto-rows: max-content`. app.js takes fake messages via `window.__papeMessage` in a plain browser (launch.json entry `pape-web`, port 8771).
- Maximized windows' rects overhang the monitor, so fullscreen detection needs `!IsZoomed`.
- `.\publish.ps1` (refuses archived versions, runs `--smoke`, keeps `Pape.exe` + `Versions\Archive`); `.\publish.ps1 -Test` builds into `test\`. `--smoke` uses throwaway data and off-screen windows and writes `smoke.txt` plus PNG captures (smoke-ui/image/web/settings) to `<out>\Pape-Data`. `Pape.exe --exit` quits a running copy.
- Scenes (0.2.0): `web/scene/` (formats.js = pkg/tex/LZ4, shaders.js = WE→GLSL ES rewrite, scene.js = renderer), `web/scene.html`; format notes in `docs\SCENE-FORMAT.md`. WE assets mapped at `we.pape.portable`. Layer buffers keep WE's top-row-first layout; effect pass slot 0 defaults to "previous"; `usershadervalues` is {userProp: materialKey}. Not yet: particles, 3D/perspective scenes (show preview), .mdl models, puppet warp, text, sound, bloom.
- Particles (0.3.0): `web/scene/particles.js` simulates on the CPU; drawing goes through the material's own WE particle shader (no-geometry-shader path, THICKFORMAT combo) with a fallback sprite shader. WE's preset preview folders (`assets\presets\*\preview*\scene.json`) are a good particle test set. Shimmering Particles still renders brighter/denser than WE's preview (unresolved: maybe z-culling or blending). Not yet: child systems, ropes, boids.
- 3D (0.4.0): `web/scene/model.js` reads .mdl v4/14/23 (format in docs\SCENE-FORMAT.md); scene.js has perspective camera + camera paths, depth, point lights. `#require LightingV1` is WE-generated per scene and absent from assets; shaders.js substitutes a loop over `pape_Lights*` uniforms. All 8 3D samples render (Audiophile's bars need audio). Not yet: skinned/animated models, shadows, bloom, fur.
- Bloom (0.5.0) runs WE's own util passes (downsample_quarter_bloom, downsample_eighth_blur_v, blur_h_bloom, combine) with full-frame g_TexelSize. 3D draw order: only runs of translucent/additive depth-tested models are sorted far-to-near; opaque models/backgrounds keep scene order (sorting everything broke DNA Fragment's background).
- Puppet warp (0.6.0): MDLS/MDLA parsed in model.js (format in docs\SCENE-FORMAT.md), CPU skinning in scene.js `skin()`; the puppet mesh covers only visible pixels. Objects have `parent` ids (children placed through the chain). Test wallpaper: Workshop 3689603596 (Arknights, blinking). Owner is wary of depending on Steam; the "keep own copies" step (copy WE assets + Workshop items into Pape-Data) was offered, not built. One Workshop effect (Simple_Audio_Bars) stays unsupported: implicit float→uint in HLSL style.
- Scene testing outside Pape: scratch site with junctions to `web\` and the WE install, served by a small Python server that accepts PUT of renders; the workspace launch.json has `pape-scene-test`. In a hidden browser pane `Image.decode()` never resolves (use createImageBitmap) and WebGL canvases must be copied in the same task as render. rAF stops in hidden/off-screen windows, so scene.html also ticks on a 50 ms timer.
- The self-check sets all playback rules to keep: otherwise the owner's fullscreen window pauses the test wallpapers.
